프로젝트1

AI 데이터센터(AIDC) 일일동향 자동화 시스템

AI 데이터센터(AIDC) 관련 정부기관·공기업 보도자료와 지자체·국내외 기업 뉴스를 매시간 자동으로 수집하고, Claude API로 동향을 분석·요약해 실시간 웹사이트로 배포하는 업무 자동화 시스템입니다. 기획부터 개발·배포·운영까지 전 과정을 직접 담당하며, 사람이 매일 여러 기관 사이트를 일일이 확인하던 모니터링 업무를 수집 → 분석 → 배포가 자동으로 이어지는 파이프라인으로 전환했습니다.

  • Python
  • Cloudflare Workers
  • Claude API
  • GitHub Actions
역할기획·개발·배포·운영 전담 (1인)
자동화 구조로컬 Python 수집 + Cloudflare Workers(Cron) 실시간 수집·분석 + GitHub Actions 자동 배포
해결한 문제정부기관 사이트의 클라우드 IP 차단을 요청 로그로 진단 → 로컬 환경 이전 및 Cloudflare AI Gateway 우회 경로로 해결
사용 도구Python, BeautifulSoup, Cloudflare Workers, Claude API, GitHub Actions
