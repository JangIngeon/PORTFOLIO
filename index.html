기술적으로 해결한 문제

① 클라우드 IP 차단 대응

정부기관 웹사이트가 GitHub Actions 등 클라우드 서버의 접속을 방화벽(WAF) 차원에서 차단하는 것을 요청 실패 로그로 확인하고, 해당 수집 로직만 로컬 환경으로 이전해 안정성을 확보했습니다.
이후 Cloudflare에서 Anthropic API를 호출할 때도 동일한 유형의 403 차단이 발생하는 것을 재확인하고, Cloudflare AI Gateway를 경유하는 우회 경로를 구축했습니다.

② 데이터 중복·오분류 문제 해결

동일 기사가 지자체·국내기업·해외기업 세 카테고리에 중복으로 노출되는 문제를 발견하고, 링크 기준 전역 중복 제거 로직과 텍스트 내 언급 빈도 기반 우선순위 배정 알고리즘을 설계·구현했습니다.
또한 "대전"과 "대전환"처럼 단순 문자열 포함 검사로는 걸러지지 않는 오분류 문제를, 한국어 조사·행정구역 접미사 경계를 인식하는 매칭 로직을 직접 설계해 해결했습니다.

③ AI 생성 콘텐츠의 신뢰도 확보

AI가 사실과 다른 내용(인물 직함 오기, 연도 오기 등)을 생성하는 문제를 발견하고, 초안을 원본 자료와 대조해 교정하는 2단계 팩트체크 검증 로직을 직접 설계·구현했습니다.

④ 성능 및 비용 최적화

반복적으로 같은 참고 자료를 나눠 보내던 여러 번의 검증 API 호출을 하나의 통합 요청으로 묶어, 실행 시간과 토큰 사용량을 동시에 절감했습니다.

배운 점

  • 실무 데이터의 모호성과 예외 처리(Edge-case) 극복. 실제 비즈니스 환경의 데이터는 이상적이지 않으며, 유사 키워드나 복합 카테고리 기사처럼 단일 규칙으로는 분류하기 어려운 모호성이 존재함을 인지하고, 한국어 조사 및 행정구역 접미사 패턴을 고려한 정규식을 설계함. 안정적인 자동화는 정교한 도메인 규칙 정제에서 시작됨을 확인함.
  • 인공지능 도입 시 데이터 정합성(Integrity) 확보 및 품질 관리 체계 구축. 거대언어모델을 실무에 적용할 때 발생하는 환각(Hallucination) 리스크를 제어하기 위해 원본 기사와 대조하는 2단계 팩트체크 로직을 설계함. 업무 자동화 현장에서는 생성 속도보다 검증 가능한 정확성이 핵심 원칙임을 바탕으로 품질 검증 체계를 확립함.
  • 현상에 의존하지 않는 근본 원인 분석(Root-Cause Analysis) 관점. 정부기관 웹사이트의 클라우드 IP 차단 이슈를 다루며 단순 오류 메시지에 의존하지 않고, 네트워크 요청·응답 로그를 단계별로 검증하는 체계적 디버깅 프로토콜을 확립함.

③ AI 코딩 도구 활용과 직접 검증

프론트엔드 개발 경험이 깊지 않은 상태에서 Claude(Anthropic AI 코딩 어시스턴트)를 활용해 코드 초안과 UI 구현 속도를 높였습니다.

배운 점

  • 산식 정확도를 넘어선 '설득력 있는 데이터(Explainability)' 설계의 중요성. 복잡한 재무 산식을 정확히 구현하는 것만큼 의사결정권자가 산식의 기준을 쉽게 납득하는 것이 중요함을 확인하고, '산식 및 기준값 공개 패널'을 인터랙티브 도구 내에 탑재해 불필요한 의사소통 비용을 제거하고 데이터의 신뢰성을 확보함.
  • 정적 보고서에서 '동적 시나리오 분석 도구'로의 가치 확장. 완성된 보고서를 제출하는 것에 그치지 않고, 경영진과 실무자가 직접 주요 변수를 조작하며 시나리오별 손익 변화를 검증할 수 있는 인터랙티브 대시보드를 구축함으로써, 실무 분석가의 역할이 단순한 계산을 넘어 전략적 선택지를 신속하게 제공하는 데 있음을 확인함.
  • 인공지능 코딩 도구 활용 시 분석가의 주도권(Ownership) 유지 원칙. 개발 보조 도구를 활용해 UI 프로토타입 구현 속도를 높이면서도, 핵심 재무 산식과 비즈니스 논리의 검증은 분석가가 주도적으로 제어해야 한다는 실무적 밸런스를 체득함.

Why · What · How

WHY (왜 분석했는가?)
10년 넘게 운영된 국가 체육 프로그램(국민체력100)이 실제로 국민의 비만과 의료비를 줄여 예산 값을 하고 있는지 데이터로 증명된 적이 없었기 때문입니다.

WHAT (무엇을 발견했는가?)
통계 분석 결과, '10~20대 청년층'은 체력 측정을 받을수록 비만이 확실하게 감소했지만, '60대 이상 노년층'은 단순 측정만으로는 효과가 없거나 오히려 역효과가 났습니다.

HOW (어떻게 활용했는가?)
"모든 세대에 똑같이 예산을 쓰지 말고, 청년층은 참여 확대를, 노년층은 방문 지도 등 맞춤형 처방 프로그램으로 예산을 재배치해야 한다"는 실질적 정책 전략을 이끌어냈습니다.

핵심 성과

  • 측정건수 1건 증가 시 비만환자수 코호트 평균 0.0036명 감소 (All 모형 β=-0.0036, Drop 모형 β=-0.0028, 두 모형 모두 p<0.01)
  • 월 평균 요양급여비용총액 약 1,150원, 보험자부담금 약 780원 절감 (All 모형 β=-1.1484, β=-0.7825, 각각 p<0.05) — 세 핵심 지표 모두 통계적으로 유의한 인과적 감소 효과를 실증
  • 대조군·개인 패널이 없는 전국 단위 정책 환경에서 14개 코호트(성별2×연령대7)×36개월(2022~2024) = 504개 관측치 Pseudo-panel을 설계해 인과관계를 규명
  • 10~20대 청년층에서 효과가 가장 뚜렷한 반면, 일부 고령 코호트에서는 통계적으로 유의한 역방향(효과 반전) 결과를 확인 — 연령대별 자원 최적 배분 전략을 정책 제안으로 도출해 학술지 논문에 수록 (기여도 60%, 2저자)

프로젝트 개요

국민체육진흥공단의 국민체력100은 10년 이상 운영된 국가 체육 프로그램이지만, 실제로 비만이 줄었는지 의료비가 감소했는지를 숫자로 증명한 연구가 없었습니다.
저는 흩어진 공공데이터를 분석 가능한 형태로 재구성하고, 통계 분석으로 그 효과를 실증했습니다.

문제 인식

① 개인 데이터의 부재

참여자 한 명 한 명을 장기적으로 추적할 수 있는 개인 패널 데이터가 존재하지 않았습니다. 반복 횡단면 구조의 데이터로, 전통적 분석 방법이 불가능한 상황이었습니다.

② 비교 대상의 부재

전국 모든 센터에서 동시에 시행되는 프로그램이라 "참여하지 않은 집단"이라는 비교군이 존재하지 않아, 기존 분석 틀을 그대로 쓸 수 없었습니다.

③ 상관관계에 그친 기존 연구

기존 연구는 두 시점 비교에 그쳐, 프로그램이 실제로 효과가 있었는지 인과적으로 증명하지 못하고 있었습니다.

사고 전환

"개인을 추적할 수 없다면, 집단을 개인처럼 다루면 된다."

개인 단위 데이터가 없다는 조건을 뒤집어, 성별·연령대·월을 묶어 집단 자체를 하나의 관측 단위로 재정의했습니다. 없는 데이터를 찾는 대신, 있는 데이터로 새로운 구조를 설계했습니다. 이 아이디어가 이후 분석 전체의 기반이 된 Pseudo-panel입니다.

데이터 설계

핵심은 개인이 없어도, 집단을 고정하면 시간 흐름을 추적할 수 있다는 점이었습니다. 이를 통계적으로 엄밀하게 검증하기 위해 4단계 파이프라인을 설계했습니다.

정책 제안

분석에서 그치지 않고, 연령대별 효과 이질성을 근거로 집단별 맞춤 전략을 논문에 직접 제안했습니다.

청년층(10~30대) — 현행 방식 강화·지속

효과가 뚜렷하게 확인됨. 현재의 측정 중심 참여 방식을 유지하면서 참여율을 높이는 방향으로 운영해야 함.

중년층(40~50대) — 효과 이질성 주의

집단 내 반응 편차가 큼. 개인별 운동처방 강도를 세분화해 적용할 필요가 있음.

노년층(60~70대) — 별도 프로그램 설계 필요

단순 참여만으로는 효과가 없는 수준을 넘어, 일부 코호트에서는 통계적으로 유의한 역방향(효과 반전) 결과까지 확인됨. 측정 중심 참여만으로는 한계가 있다는 뜻으로, 방문형 운동지도·장기 모니터링·질환관리 중심 처방을 별도로 설계해야 함.

배운 점

  • 문제 재정의. 막혔을 때 구조를 바꿈. 개인 데이터가 없다는 한계를 집단 단위로 재정의해 돌파함. 없는 것을 찾는 대신 있는 것으로 새로운 구조를 설계함.
  • 통계적 사고. 현상을 숫자로 검증함. 직관이나 경험에 의존하지 않고 통계적 방법론으로 인과관계를 증명함. "효과가 있는 것 같다"를 "효과가 있다"로 바꾸는 과정을 직접 설계함.
  • 인사이트 → 실행. 데이터를 전략으로 연결함. 분석 결과를 보고서로 남기는 데 그치지 않고, 집단별 맞춤 정책 제안으로 논문에 명시함.

Why · What · How

WHY (왜 분석했는가?)
"어딜 가든 1시간 반"이 걸린다는 시민들의 체감 민원과 지자체의 현실적 제약이 부딪히는 상황에서, 데이터 분석가로서 의견을 하나로 수렴할 수 있는 객관적 기준점을 만들기 위해 시작했습니다.

WHAT (무엇을 발견했는가?)
인천교통정보센터 실시간 통행 속도 API와 신호 데이터를 덤벨차트로 비교 분석한 결과, 평시 대비 출퇴근 속도 하락 폭이 가장 크고 혼잡 빈도가 집중된 병목 중심지가 '송도 아트센터대로'임을 규명했습니다.

HOW (어떻게 해결했는가?)
모니터 앞 분석에 그치지 않고 현장 인터뷰와 교통 인프라 검증을 거쳐, 1) 카풀 지역화폐 마일리지, 2) 피크타임 혼잡통행료, 3) 수요 맞춤형 노선 최적화라는 3대 현실적 솔루션을 제안했습니다.

핵심 성과

  • 이해관계자(시민-공무원-연구원) 간 평행선을 달리던 의견을 인포그래픽/보고서 시각화를 통해 단일 해결 주제로 수렴
  • 인천교통정보센터 API 및 신호 체계 데이터를 직접 요청·가공하여 출퇴근 정체 우선 순위 지역 정량 도출
  • 비전공자도 평시 vs 출퇴근 속도 차이를 직관적으로 공감할 수 있는 '덤벨차트' 기반 데이터 설득 시각화 구현
  • 데이터 분석-현장 인터뷰 교차 검증을 통해 인천시 관계자로부터 "향후 교통 정책 적용 시 긍정적 검토" 공식 피드백 수령

복잡한 지도나 기술 언어 대신, '평상시 속도(하늘색)와 출퇴근 시간대 속도(주황색)의 하락 폭(선 길이)'을 직관적으로 보여주는 덤벨차트를 설계했습니다. 비전공자인 시민과 지자체 담당자도 "왜 송도 아트센터대로를 최우선 타깃으로 잡아야 하는가"를 단 한눈에 이해하고 동의할 수 있었습니다.

데이터와 현장의 결합 : 3대 해결 정책 제안

숫자 뒤의 맥락을 읽기 위해 팀원들과 송도 아트센터대로 현장을 직접 탐방하고 지역 거주 시민 인터뷰를 병행했습니다. 그 결과, 회사와 상가가 밀집한 도시임에도 해당 구간을 통과하는 버스/지하철의 배차 간격이 길고 노선이 비효율적이어 자차 통근 의존도가 높다는 근본 원인을 찾아냈고, 이를 해결할 3가지 정책을 제안했습니다.

① 직장인 카풀 지역화폐 연계

② 피크타임 혼잡통행료 징수

③ 통근 수요 맞춤 노선 최적화

시민들의 혼잡 시간대 이동 경로 데이터를 기반으로 배차가 길었던 버스 노선 및 배차 간격을 리바운드하는 공급 최적화 전략

배운 점 (Key Takeaway)

  • 소통하는 분석가의 진짜 역할. 다양한 직군(시민, 지자체 공무원)이 모인 회의에서 데이터 분석은 단지 화려한 기술을 보여주는 것이 아니라, '서로 다른 이해관계를 데이터라는 공통의 언어로 묶고 합의점을 만들어내는 설득의 도구'임을 체득함.
  • 1인 분석 환경에서의 유연한 의사결정. 당시 혼자 분석을 맡아 고도화된 실시간 지도 시각화를 구현하기에 제약이 있었지만, 좌절하는 대신 핵심 메시지가 명확한 덤벨차트와 현장 인터뷰(정성 데이터)를 상호 보완하여 의사결정권자들의 공감과 정책 긍정 검토를 이끌어냄.
