# 숏폼 차단기 (Shorts & Reels Blocker)

유튜브 쇼츠 / 인스타그램 릴스를 **차단**하거나 **하루 시청 시간을 제한**하는 크롬 확장 프로그램입니다.

## 설치
1. 크롬에서 `chrome://extensions` 접속 → 우측 상단 **개발자 모드** 켜기
2. **압축해제된 확장 프로그램을 로드합니다** → 이 `shorts-blocker` 폴더 선택
3. 툴바의 아이콘을 눌러 사이트별 모드를 설정

## 모드
- **완전 차단**: 쇼츠/릴스 페이지 접근 시 홈으로 돌려보내고, 쇼츠 선반·메뉴·썸네일을 숨깁니다.
- **하루 시간 제한**: 쇼츠/릴스 화면을 *보고 있는 시간*만 누적하여 제한 시간 도달 시 홈으로 이동합니다. 자정(로컬 시간)에 초기화됩니다.
- **끄기**: 아무 동작 안 함.

## 한계
- 데스크톱 크롬 계열(Edge, Brave 등 포함) 웹 전용입니다. 모바일 앱은 막지 못합니다.
- 인스타그램 피드 중간에 섞인 릴스는 일반 게시물과 구분이 어려워 완전히 막지 못할 수 있습니다(릴스 탭/링크는 차단).
- 두 사이트의 DOM이 바뀌면 숨김 CSS 선택자 업데이트가 필요할 수 있습니다.
